# 浓缩生产 CondensedProduction

戴森球计划 Mod：让任意配方生产建筑可以设定倍率 N，**等效于 N 台相同建筑合为一体**。

例如把一台熔炉设为 3 倍：生产时间不变，每次生产的原料消耗与产物产出等效于 3 台熔炉同时工作，能耗也为 3 倍——总资源消耗与放 3 台熔炉完全一致，但无需再铺开产线。

## 功能特性

### 1. 浓缩生产（倍率上限 1000）

- **支持建筑**：熔炉、制造台、化工厂、原油精炼厂、粒子对撞机等所有 Assembler 类建筑，以及科研站（制造模式）
- **周期时间不变**：原版配方多少时间就是多少时间，改变的只是「一个周期吃多少料、出多少产物」
- **自适应实际倍率**：实际运行倍率 = min(设定倍率, 当前输入缓存可支撑的周期数)
  - 例：设定 5 倍，若输入只能支撑 3 倍，则自动按 3 倍运行；输入补足后自动回到 5 倍
- **能耗同步**：能耗 = 实际运行倍率 × 基础能耗
- **存储扩容**：原料缓存随倍率放大；熔炉/装配机的产物缓存上限按设定倍率放大（可在配置中关闭）
- **增产剂兼容**：与喷涂增产（加速/增产）效果正确叠乘
- **存档安全**：倍率数据通过 DSPModSave 独立保存，不修改原版存档结构

### 2. 容器容量 ×100

物流站（行星/星际）、储物箱、储液罐、玩家背包的**每格上限**统一放大 100 倍（配置可调）。只改容量上限，不改物品与堆叠格式。

### 3. 传送带堆叠扩容

堆叠器、白爪（本体最高级分拣器）、物流塔出口按最高层数输出，库存不足时按实际数量输出。

> 技术说明：游戏内每个物品的堆叠数存为单字节（`Cargo.stack`），**最大 255**（原版最高 4 层），因此 ×100 = 400 无法表示，本 mod 取字节能容纳的 255 层。该字段类型无法在不破坏存档兼容性的前提下修改。

渲染保持原版：逻辑上堆叠 255 层，绘制时临时按 4 层显示，画面与原版一致。

### 4. 无线供料

在倍率面板上开启「无线：开」后，该建筑**无需分拣器**，直接由本行星的行星物流站 / 星际物流站供料，并把产物直接回收到物流站：

- **直供**：从本行星所有物流站的库存里补料到该建筑倍率对应的原料上限（补满即停）
- **回收**：产物缓冲里的产物直接并入物流站库存（受每格上限约束）
- **开关独立于倍率**：开不开倍率都可以开无线；只有开启无线的建筑才享受直供直收
- **人不在场也生效**：扫描遍历全星系所有已加载行星的工厂，不要求玩家在该行星
- 与是否使用分拣器兼容：同时接线也能正常工作
- 复制建筑设置（窗口复制 / 整栋框选复制）时，倍率与无线开关一并复制

## 安装

### 方式一：Thunderstore Mod Manager / r2modman（推荐）

1. 确保已安装 BepInEx 5 与 CommonAPI-DSPModSave（Mod Manager 会自动处理依赖）
2. 搜索 `CondensedProduction` 安装，或把 zip 拖入 Mod Manager

### 方式二：手动安装

1. 确认游戏目录已配置 BepInEx 5，且 `BepInEx/plugins` 下已有 `DSPModSave.dll`
2. 把 `CondensedProduction.dll` 放到 `BepInEx/plugins/CondensedProduction/`

## 使用

1. 打开任意支持的生产建筑窗口（点击建筑）
2. 窗口外侧会出现「浓缩生产」面板（可拖动，不会挡住原版窗口标题栏）
3. 用 `-10 / -1 / +1 / +10` 微调，或点击 `1 / 5 / 10 / 100 / 1000` 快捷设定，也可输入任意数字后点「应用输入」
4. 面板实时显示「设定 xN / 实际 xM」；设为 1 即恢复原版行为
5. 需要免分拣器直供时，点一下「无线：关」使其变为「无线：开」

## 配置

配置文件：`BepInEx/config/com.mandao.CondensedProduction.cfg`（首次运行后生成）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 通用 / MaxMultiplier | 1000 | 单建筑倍率上限（0 = 不限制） |
| 通用 / ScaleOutputStorage | true | 是否按设定倍率放大产物缓存上限 |
| 通用 / InputBufferMultiplier | 3 | 原料缓存系数：上限 = 原版上限 × 倍率 × 该值 |
| 通用 / ContainerMultiplier | 100 | 容器每格容量倍数 |
| 无线供料 / Enabled | true | 启用无线供料 |
| 无线供料 / IntervalTicks | 30 | 无线供料执行间隔（游戏刻） |
| 无线供料 / Collect | true | 是否把无线建筑的产物回收到物流站 |
| 传送带堆叠 / Enabled | true | 启用堆叠扩容 |
| 传送带堆叠 / MaxStack | 255 | 堆叠上限（1~255） |
| 传送带堆叠 / KeepVisualStack | true | 绘制时压回 4 层，保持原版画面 |

## 测试要点

1. 放置一台熔炉接好输入输出，设为 3 倍：核对产出总量 ≈ 3 台熔炉
2. 把输入减半：实际倍率应自动下降（面板显示可见），补足后自动恢复
3. 观察电网：设定 5 倍时建筑功耗应为 5 倍，且同一周期内不来回跳变
4. 设为 1000 倍并接上物流站：应在数秒内补满原料并开始批量生产
5. 容器：物流站 / 储物箱的单格容量应约为原版 100 倍
6. 传送带：串上堆叠器后，带上物品堆叠数应远高于 4，且画面仍为原版样式
7. 白爪从满层传送带取料、物流塔出口出料，应呈现高层堆叠
8. 无线：开启无线并拆除所有进料分拣器，建筑仍应持续生产，产物自动进入物流站
9. 换到另一颗行星 / 关闭建筑窗口，回来后无线建筑仍在正常供料
10. 复制建筑（窗口复制与整栋框选复制），倍率与无线开关应一并复制
11. 保存并重新载入：倍率、无线开关、物流站库存、传送带物品均应正常
12. 设为 1 倍后行为应与原版一致

## 兼容性

- **依赖**：BepInEx 5、CommonAPI-DSPModSave，无其他前置
- 与 UXAssist、BlueprintTweaks 等常见 mod 无已知冲突
- **StackingPlus 冲突**：两者都改堆叠上限，请只启用其中一个
- 与 PlanetwideSupplier / PlanetwideCollector 功能重叠（本 mod 只对开启无线的建筑生效），建议只保留一种
- Nebula 联机：未测试，倍率状态可能不会同步给客机
- 拆除建筑后，同行星同 entityId 的新建筑会继承原倍率（可视为重建保留设置）

## 卸载

把所有建筑倍率设回 1（或直接卸载，残留数据不影响存档），然后删除本 mod。
